# OTOasobi

オトアソビ。UTAU 音源ライブラリ用の、原音設定自動推定ソフトです。制作途中です。

音源フォルダの WAV を読み、ファイル名（読み仮名）と音響から原音設定（`oto.ini`）の各値を推定することを目指しています。画面は WinUI 3、解析は Python です。

## いまできること

いま書き出す原音設定は、単独音モードです。

- フォルダを選ぶか、ウィンドウへドロップして、その中の WAV をまとめて解析する
- ファイル名をモーラに分解し、子音と母音に分けて時間を割り当てる
- 波形とメルスペクトログラムの上に区間を出し、境界やラベルをドラッグして直す
- 「oto.ini作成」で、直した区間から単独音の `oto.ini` を計算し、選んだフォルダに ANSI（CP932）で保存する
- 母音（`N` と `M` を含む）の始まり時刻を、`OTOasibi_out.txt` に残す
- 無音・子音・母音の全区間は、`OTOasibi_log.txt` に残す
- 高精度エンジン（MMS 強制アライメントと Praat）があるときはそちらを使い、無いときは音響特徴だけで解析する

## 単独音モード

`oto.ini` の 1 行は次の形です。数値はミリ秒で、小数第 3 位までです。

```text
ファイル名.wav=エイリアス,オフセット,子音部,ブランク,先行発声,オーバーラップ
```

エイリアスは、そのモーラのかなです。空のときは、拡張子を除いたファイル名になります。`ん` は `N` でも `M` でも 1 エイリアスで、名前は `ん` です。母音だけの音と `ん` は、子音の開始を母音の開始と同じにします。

| 欄 | ファイル上の位置 | oto.ini での測り方 |
| --- | --- | --- |
| オフセット | 子音の開始から、スライダーで ±0.1 秒 | ファイル先頭から。0 未満にはしない |
| 先行発声 | 母音の開始 | オフセットから。0 未満にはしない |
| オーバーラップ | 子音の開始と終了のあいだ。割合は子音ごと（初期値 50%） | オフセットから。負の値も書く |
| 子音部 | 母音の開始から、スライダーで 0〜0.2 秒後 | オフセットから。0 未満にはしない |
| ブランク | 音量の上辺の右端から、スライダーの秒数だけ前後 | オフセットからの時間に -1 を掛けた値 |

オフセットのスライダーは、子音の開始を 0 とします。マイナスは手前、プラスは後で、幅は ±0.1 秒です。

子音部のスライダーは、母音の開始を 0 秒とします。後へずらすだけで、幅は 0〜0.2 秒です。初期値は 0.2 秒です。

ブランクは、その母音の音量から上辺の右端を取り、スライダーの秒数だけ前後にずらします。0 秒がその角です。プラスは減衰側、マイナスは手前です。幅は ±0.1 秒です。角が取れない短い母音は、母音の終了から同じ秒数だけずらします。ビブラートで角が揺れるときは、揺れの幅まで上辺を広げます。

子音の終了は、母音の開始です。ブランクと子音部のあいだが 1ms 未満になるときは、ブランクを後ろへずらします。ファイルの末尾を超えるときは、子音部を縮めて 1ms を空けます。

オーバーラップは、子音の開始から母音の開始までの割合です。0% が子音の開始、100% が母音の開始で、初期値は 50% です。スライダーは子音の種類ごとにあり、`k` と `sh` のように別の割合を置けます。母音だけの音と `ん` は、子音の開始と母音の開始が同じなので、割合を変えても位置は動きません。

## 必要環境

- Windows
- .NET 10 SDK（画面）
- Python 3.12（解析）

解析の依存は `requirements.txt` です。

- numpy
- soundfile

高精度エンジンは `requirements-precision.txt` の `praat-parselmouth`、`torch`、`torchaudio` です。`.venv` に入っているとき、OTOasobi の解析でも使います。

## セットアップ

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-precision.txt
```

.NET 10 SDK は [ダウンロードページ](https://dotnet.microsoft.com/download) から入れます。入っているかは `dotnet --version` で確認できます。

## 起動

```powershell
dotnet run --project winui
```

起動するとフォルダ選択が開きます。画面の「フォルダを選択またはドラッグ＆ドロップ」からも選べます。選んだフォルダ直下の `.wav` をすべて解析し、波形とメルスペクトログラムに区間を重ねて表示します。境界をドラッグすると隣の区間と時刻を分け、ラベルの上をドラッグするとその区間ごと移動します。直したあとに「oto.ini作成」を押すと、その区間から計算した `oto.ini` と、同じ内容の `OTOasibi_out.txt`、`OTOasibi_log.txt` をフォルダに保存します。「oto.iniを開く」で `oto.ini` を開きます。

ファイル名に使えない文字があるときは、その理由を表示します。

## ファイル名

拡張子を除いた名前が読み仮名です。使える文字はひらがな、カタカナ（`ヴ` を含む外来音）、休符 `_` だけです。半角カナの `ｳﾞ` や、濁点を離した `ウ゛` も `ヴ` として読みます。

| 記法 | 意味 |
| --- | --- |
| `そ` `せ` `しゃ` `つ` | 1 モーラ。拗音・外来音は 2 文字で 1 モーラ |
| `_` | 休符。連続した `_` は 1 つの無音 |
| 先頭の `_` | 発話前の無音 |
| 末尾の `_` | 発話後の無音 |
| 途中の `_` | モーラのあいだの無音 |

例: `_そせすそそ.wav` は、無音、そ、せ、す、そ、そ、無音、の順です。

`ん` の直後がま行・ば行・ぱ行のときはラベルが `M` になります。`っ` は閉鎖 `cl` です。同じ母音が続く `ああ` や `かあ` は、いったん 1 区間として合わせてから、元のモーラ数で等分します。

使えない文字や、単独の `ゃゅょ` はファイル名エラーになります。

## ラベルファイル

`OTOasibi_out.txt` は、母音の始まり時刻だけです。タブ区切り、UTF-8、1 行が 1 モーラです。

```text
かな	母音の開始秒
```

ラベル名は、そのモーラのかなです。子音から母音へ入る時刻、前の母音から次の母音へ入る時刻を出します。`ん` は `N` でも `M` でも母音と同じように扱い、ラベル名は `ん` です。無音、息、子音、`っ` の行は出しません。

`ぱんぱぱぴぱぷあ.wav` の音素が `無音 p a N p a p a p i p a p u a` のとき、着目するのは `(p→a) (a→N) (p→a) (p→a) (p→i) (p→a) (p→u) (u→a)` です。

```text
[ぱんぱぱぴぱぷあ.wav]
ぱ	0.180000
ん	0.420000
ぱ	0.610000
ぱ	0.790000
ぴ	0.980000
ぱ	1.160000
ぷ	1.350000
あ	1.540000
```

## ログファイル

`OTOasibi_log.txt` は、推定に使った全区間です。無音、息、子音、母音を残します。1 行が 1 区間です。

```text
開始秒	終了秒	音素	かな
```

`_そせすそそ.wav` の例:

```text
0.000000	0.160000	無音	_
0.160000	0.238390	s	そ
0.238390	0.652494	o	そ
0.652494	0.732381	s	せ
0.732381	1.162494	e	せ
```

音素はローマ字です。母音は `a i u e o`、子音は `s` `sh` `k` `ts` `ch` など、撥音は `N` または `M`、促音は `cl` です。かな列は、その区間が属すモーラの表記です。開発用画面で 1 ファイルを解析したときは、同じ内容を `ファイル名.log.txt` に保存します。

## 解析エンジン

| エンジン | 内容 |
| --- | --- |
| 高精度 (MMS+Praat) | torchaudio の MMS-FA で文字を合わせ、Praat で発話区間・声帯振動・フォルマントを補正する |
| 高精度 (MMS) | MMS-FA のみ。Praat が無い、または使えないとき |
| 音響 | RMS、高域比、ゼロ交差、スペクトル変化だけで区間を切る |

高精度の読み込みに失敗したときは音響へ戻ります。

## 開発用の確認画面

`app.py` は解析結果を波形とメルスペクトログラムで見るための開発用画面です。OTOasobi には組み込みません。

```powershell
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m otoasobi.cli そせす.wav
```

開発用画面の exe は `powershell -File scripts\build_exe.ps1` で、`dist\OtoasobiLabel\OtoasobiLabel.exe` に出力されます。高精度エンジンは同梱しません。
