# OTOasobi

オトアソビ。UTAU 音源ライブラリ用の、原音設定自動推定ソフトです。制作途中です。

音源フォルダの WAV を読み、ファイル名（読み仮名）と音響から原音設定（`oto.ini`）の各値を推定することを目指しています。画面は WinUI 3、解析は Python です。

## いまできること

いま書き出す原音設定は、単独音、連続音、CVVC です。oto調整の上で切り替えます。

- フォルダを選ぶか、ウィンドウへドロップして、その中の WAV をまとめて解析する
- ファイル名をモーラに分解し、子音と母音に分けて時間を割り当てる
- 波形とメルスペクトログラムの上に区間を出し、境界やラベルをドラッグして直す
- 「oto.ini作成」で、直した区間から、選んでいるモードの `oto.ini` を計算し、選んだフォルダに ANSI（CP932）で保存する
- 母音（`N` と `M` を含む）の始まり時刻を、`OTOasibi_out.txt` に残す
- 無音・子音・母音の全区間は、`OTOasibi_log.txt` に残す
- 高精度エンジン（MMS 強制アライメントと Praat）があるときはそちらを使い、無いときは音響特徴だけで解析する
- ファイルメニューの「設定を保存」で、計算方法、スライダー、プリセットを開いているフォルダに残し、「設定を読み込む」で戻せる

## 単独音モード

`oto.ini` の 1 行は次の形です。数値はミリ秒で、小数第 3 位までです。

```text
ファイル名.wav=エイリアス,オフセット,子音部,ブランク,先行発声,オーバーラップ
```

エイリアスは、そのモーラのかなです。空のときは、拡張子を除いたファイル名になります。`ん` は `N` でも `M` でも 1 エイリアスで、名前は `ん` です。母音だけの音と `ん` は、子音の開始を母音の開始と同じにします。

| 欄 | ファイル上の位置 | oto.ini での測り方 |
| --- | --- | --- |
| オフセット | 子音の開始から、スライダーで ±0.1 秒 | ファイル先頭から。0 未満にはしない |
| 先行発声 | 母音の開始 | オフセットから。0 未満にはしない |
| オーバーラップ | 子音の開始から母音の開始までを割合で置く（初期値 50%）。開始より前は秒数で、オフセットより前にも置く | オフセットから。負の値も書く |
| 子音部 | 母音の開始から、スライダーで 0〜0.2 秒後 | オフセットから。0 未満にはしない |
| ブランク | 音量の上辺の右端から、スライダーの秒数だけ前後 | オフセットからの時間に -1 を掛けた値 |

オフセットのスライダーは、子音の開始を 0 とします。マイナスは手前、プラスは後で、幅は ±0.1 秒です。

子音部のスライダーは、母音の開始を 0 秒とします。後へずらすだけで、幅は 0〜0.2 秒です。初期値は 0.2 秒です。

ブランクは、その母音の音量から上辺の右端を取り、スライダーの秒数だけ前後にずらします。0 秒がその角です。プラスは減衰側、マイナスは手前です。幅は ±0.1 秒です。角が取れない短い母音は、母音の終了から同じ秒数だけずらします。ビブラートで角が揺れるときは、揺れの幅まで上辺を広げます。

子音の終了は、母音の開始です。ブランクと子音部のあいだが 1ms 未満になるときは、ブランクを後ろへずらします。ファイルの末尾を超えるときは、子音部を縮めて 1ms を空けます。

オーバーラップは、子音の開始から母音の開始までの割合です。0% が子音の開始、100% が母音の開始で、初期値は 50% です。スライダーは子音の種類ごとにあり、`k` と `sh` のように別の割合を置けます。0% で左へ引いているあいだは値を変えず、離すとその行が秒のスライダーになります。最大 0.1 秒で、オフセットより前にも置きます。右端まで戻して離すと、割合のスライダーに戻ります。母音だけの音と `ん` は、子音の開始と母音の開始が同じなので、割合を変えても位置は動きません。

## 連続音モード

行の形と、子音部・ブランク・先行発声の測り方は、単独音と同じです。エイリアスは、直前の母音と、そのモーラのかなです。`あかい` なら `- あ`、`a か`、`a い` です。先頭と、休符のあとは `-` です。`ん` の母音は `n` です。

| 欄 | ファイル上の位置 | oto.ini での測り方 |
| --- | --- | --- |
| オフセット | その音素の子音と直前の母音の境界から 0.15 秒手前。子音がないときは、母音と母音の境界から 0.15 秒手前。スライダーは ±0.1 秒 | ファイル先頭から。0 未満にはしない |
| 先行発声 | 母音の開始 | オフセットから。0 未満にはしない |
| オーバーラップ | オフセットの位置を 0%、その音素の開始を 100% とした割合。初期値は 50% | オフセットから。負の値も書く |
| 子音部 | 単独音と同じ。母音の開始から 0〜0.2 秒 | オフセットから。0 未満にはしない |
| ブランク | 単独音と同じ。音量の上辺の右端から、スライダーの秒数だけ前後 | オフセットからの時間に -1 を掛けた値 |

音素の開始は、子音と直前の母音の境界です。子音がないときは、母音と母音の境界です。オーバーラップは、オフセットの位置とその境界のあいだを割合で分けます。子音ごとのスライダーはありません。

アンダーバーだけの無音の直後の音素は、単独音と同じ計算です。使う値は、連続音の画面で選んだ単独音のプリセットです。初期値は、オフセット 0、子音部 0.2 秒、ブランク 0、オーバーラップ 50% です。エイリアスは連続音のままです。`_あかい` の `- あ` がこれにあたり、続く `a か` と `a い` は連続音の計算です。`っ` から始まる音も、そのモーラの直前が無音なら単独音の計算です。

## CVVC モード

1 つの WAV から、通常の音素と、そのあいだの子音音素を書きます。`さしす` なら、並びは `- さ`、`a sh`、`し`、`i s`、`す` です。`っ` と、子音の無い `ん` には子音音素の行はありません。子音があるモーラだけ、その通常音素の前に子音音素が入ります。

先頭音素は、ファイルの先頭と、アンダーバーだけの無音の直後です。計算は選んだ単独音のプリセットで、単独音と同じです。エイリアスは `-` と、そのモーラのかなです。あいうえおんは、ファイルの先頭ではこのプリセットを使わず、下の母音音素の計算です。アンダーバーの直後は、あいうえおんでもこのプリセットです。

通常音素は、先頭以外で、子音があるモーラです。エイリアスは、そのモーラのかなだけです。

| 欄 | ファイル上の位置 | oto.ini での測り方 |
| --- | --- | --- |
| オフセット | 子音の開始。スライダーはありません | ファイル先頭から。0 未満にはしない |
| 先行発声 | 母音の開始。単独音と同じ | オフセットから。0 未満にはしない |
| オーバーラップ | オフセットを 0%、先行発声を 100% とした割合。初期値は 50%。子音ごとにスライダーがあります | オフセットから |
| 子音部 | 単独音と同じ。母音の開始から 0〜0.2 秒 | オフセットから。0 未満にはしない |
| ブランク | 単独音と同じ。音量の上辺の右端から、スライダーの秒数だけ前後 | オフセットからの時間に -1 を掛けた値 |

オーバーラップに、0% より前を秒で置く機能はありません。このスライダーと、通常音素の子音部・ブランク、子音音素のスライダーは、単独音とは別のプリセットに保存します。

母音音素は、あいうえおんです。`を` と小書きの母音も同じです。子音音素の行はありません。エイリアスは、ファイルの先頭なら `- あ`、それ以外なら `あ` です。計算は連続音と同じです。オフセットとオーバーラップは子音音素のスライダー、子音部とブランクは通常音素のスライダーです。

| 欄 | ファイル上の位置 | oto.ini での測り方 |
| --- | --- | --- |
| オフセット | 連続音と同じ。その母音の開始から 0.15 秒手前。スライダーは子音音素のオフセットで、±0.1 秒 | ファイル先頭から。0 未満にはしない |
| 先行発声 | 母音の開始 | オフセットから。0 未満にはしない |
| オーバーラップ | 連続音と同じ。オフセットの位置を 0%、その母音の開始を 100% とした割合。初期値は 50%。スライダーは子音音素のオーバーラップ | オフセットから |
| 子音部 | 通常音素と同じ。母音の開始から 0〜0.2 秒 | オフセットから。0 未満にはしない |
| ブランク | 通常音素と同じ。音量の上辺の右端から、スライダーの秒数だけ前後 | オフセットからの時間に -1 を掛けた値 |

子音音素のエイリアスは、直前の母音と、いまの子音です。`ん` の母音は `n` です。`さ` の次の `し` は `a sh` です。オフセットとオーバーラップのスライダーは、母音音素にも使います。

| 欄 | ファイル上の位置 | oto.ini での測り方 |
| --- | --- | --- |
| オフセット | 連続音と同じ。その子音の開始から 0.15 秒手前。スライダーは ±0.1 秒 | ファイル先頭から。0 未満にはしない |
| 先行発声 | その子音が開始した秒 | オフセットから。0 未満にはしない |
| オーバーラップ | 連続音と同じ。オフセットの位置を 0%、その子音の開始を 100% とした割合。初期値は 50% | オフセットから |
| ブランク | その子音の開始を 0%、終了を 100% とした割合。初期値は 100%。子音ごとにスライダーがあります | オフセットからの時間に -1 を掛けた値 |
| 子音部 | 先行発声を 0%、ブランクの位置を 100% とした割合。初期値は 100%。子音ごとにスライダーがあります | オフセットから。0 未満にはしない |

ブランクと子音部が重なるときは、ほかのモードと同じく、あいだを 1ms 空けます。

## 必要環境

- Windows
- .NET 10 SDK（画面）
- Python 3.12（解析）

解析の依存は `requirements.txt` です。

- numpy
- soundfile

高精度エンジンは `requirements-precision.txt` の `praat-parselmouth`、`torch`、`torchaudio` です。`.venv` に入っているとき、OTOasobi の解析でも使います。

## セットアップ

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-precision.txt
```

.NET 10 SDK は [ダウンロードページ](https://dotnet.microsoft.com/download) から入れます。入っているかは `dotnet --version` で確認できます。

## 起動

```powershell
dotnet run --project winui
```

起動するとトップ画面が出ます。「既存のフォルダを選ぶ」を押すとフォルダ選択が開き、最近使用したフォルダの一覧からも開けます。ウィンドウへドロップしても開けます。選んだフォルダ直下の `.wav` をすべて解析し、波形とメルスペクトログラムに区間を重ねて表示します。境界をドラッグすると隣の区間と時刻を分け、ラベルの上をドラッグするとその区間ごと移動します。直したあとに「oto.ini作成」を押すと、oto調整で選んだモードで計算した `oto.ini` と、同じ内容の `OTOasibi_out.txt`、`OTOasibi_log.txt` をフォルダに保存します。「oto.iniを開く」で `oto.ini` を開きます。

ファイル名に使えない文字があるときは、その理由を表示します。

## 設定の保存

ファイルメニューの「設定を保存」は、いまの計算方法（単独音、連続音、CVVC）と、各モードのスライダーと、プリセットを、開いているフォルダの直下に保存します。原音修正のプリセットと、かかっているエフェクトの値も含みます。ファイル名は `OTOasibi_` で始まります。「設定を読み込む」で、そのフォルダのファイルを選んで戻します。読み込むと、プリセット一覧はそのファイルの内容になります。

スライダーや計算方法を変えると、同じフォルダの `OTOasibi_作業中.json` も更新されます。そのフォルダを次に開いたときは、その状態から始まります。`OTOasibi_作業中.json` は一覧には出ません。

## ファイル名

拡張子を除いた名前が読み仮名です。使える文字はひらがな、カタカナ（`ヴ` を含む外来音）、休符 `_` だけです。半角カナの `ｳﾞ` や、濁点を離した `ウ゛` も `ヴ` として読みます。

| 記法 | 意味 |
| --- | --- |
| `そ` `せ` `しゃ` `つ` | 1 モーラ。拗音・外来音は 2 文字で 1 モーラ |
| `_` | 休符。連続した `_` は 1 つの無音 |
| 先頭の `_` | 発話前の無音 |
| 末尾の `_` | 発話後の無音 |
| 途中の `_` | モーラのあいだの無音 |

例: `_そせすそそ.wav` は、無音、そ、せ、す、そ、そ、無音、の順です。

`ん` の直後がま行・ば行・ぱ行のときはラベルが `M` になります。`っ` は閉鎖 `cl` です。同じ母音が続く `ああ` や `かあ` は、いったん 1 区間として合わせてから、元のモーラ数で等分します。

使えない文字や、単独の `ゃゅょ` はファイル名エラーになります。

## ラベルファイル

`OTOasibi_out.txt` は、母音の始まり時刻だけです。タブ区切り、UTF-8、1 行が 1 モーラです。

```text
かな	母音の開始秒
```

ラベル名は、そのモーラのかなです。子音から母音へ入る時刻、前の母音から次の母音へ入る時刻を出します。`ん` は `N` でも `M` でも母音と同じように扱い、ラベル名は `ん` です。無音、息、子音、`っ` の行は出しません。

`ぱんぱぱぴぱぷあ.wav` の音素が `無音 p a N p a p a p i p a p u a` のとき、着目するのは `(p→a) (a→N) (p→a) (p→a) (p→i) (p→a) (p→u) (u→a)` です。

```text
[ぱんぱぱぴぱぷあ.wav]
ぱ	0.180000
ん	0.420000
ぱ	0.610000
ぱ	0.790000
ぴ	0.980000
ぱ	1.160000
ぷ	1.350000
あ	1.540000
```

## ログファイル

`OTOasibi_log.txt` は、推定に使った全区間です。無音、息、子音、母音を残します。1 行が 1 区間です。

```text
開始秒	終了秒	音素	かな
```

`_そせすそそ.wav` の例:

```text
0.000000	0.160000	無音	_
0.160000	0.238390	s	そ
0.238390	0.652494	o	そ
0.652494	0.732381	s	せ
0.732381	1.162494	e	せ
```

音素はローマ字です。母音は `a i u e o`、子音は `s` `sh` `k` `ts` `ch` など、撥音は `N` または `M`、促音は `cl` です。かな列は、その区間が属すモーラの表記です。開発用画面で 1 ファイルを解析したときは、同じ内容を `ファイル名.log.txt` に保存します。

## 解析エンジン

| エンジン | 内容 |
| --- | --- |
| 高精度 (MMS+Praat) | torchaudio の MMS-FA で文字を合わせ、Praat で発話区間・声帯振動・フォルマントを補正する |
| 高精度 (MMS) | MMS-FA のみ。Praat が無い、または使えないとき |
| 音響 | RMS、高域比、ゼロ交差、スペクトル変化だけで区間を切る |

高精度の読み込みに失敗したときは音響へ戻ります。

## 開発用の確認画面

`app.py` は解析結果を波形とメルスペクトログラムで見るための開発用画面です。OTOasobi には組み込みません。

```powershell
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m otoasobi.cli そせす.wav
```

開発用画面の exe は `powershell -File scripts\build_exe.ps1` で、`dist\OtoasobiLabel\OtoasobiLabel.exe` に出力されます。高精度エンジンは同梱しません。
