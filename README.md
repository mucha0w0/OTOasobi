# OTOasobi

オトアソビ。UTAU 音源ライブラリ用の、原音設定自動推定ソフトです。制作途中です。

音源フォルダの WAV を読み、ファイル名（読み仮名）と音響から原音設定（`oto.ini`）の各値を推定することを目指しています。配布する画面は `prototype/`、解析は Python です。画面の明暗とアクセントカラーは、タイトルバーの「編集」→「環境設定」の「見た目」で切り替えます。明暗を変えるとアプリを起動し直します。

## いまできること

いま書き出す原音設定は、単独音、連続音、CVVC です。oto調整の上で切り替えます。

- ファイル名をモーラに分解し、子音と母音に分けて時間を割り当てる
- 音量の下に出る oto.ini の線をドラッグして、その音素の値だけを直す。直したラベルの横には * が付き、スライダーを動かしてもその値は変わらない。自動推定の位置へ戻すと消える。強調している音素の線は、波形、スペクトラム、音量にも出て、そこでもドラッグできる
- oto数値表でマスをドラッグして複数選び、コピーして別のマスへ貼り付ける。数値はミリ秒です。エイリアスは oto.ini に出す行で、同じ名前の 2 回目以降には番号が付きます。子音音素は、CVVC を出すときに、子音があるモーラの前へ出ます
- 母音（`N` と `M` を含む）の始まり時刻を `OTOasibi_out.txt` に、無音・子音・母音の全区間を `OTOasibi_log.txt` に残す
- 高精度エンジン（MMS 強制アライメントと Praat）があるときはそちらを使い、無いときは音響特徴だけで解析する
- 表示の「frqエディター」で、選択中の `.frq` をピアノロールの点として見て、範囲をオクターブ移動するか、音程なしにするか、ペンで高さを書き換える

## oto.ini 共通

`oto.ini` の 1 行は次の形です。数値はミリ秒で、小数第 3 位までです。

```text
ファイル名.wav=エイリアス,オフセット,子音部,ブランク,先行発声,オーバーラップ
```

| 欄 | oto.ini での測り方 |
| --- | --- |
| オフセット | ファイル先頭から。0 未満にはしない |
| 先行発声 | オフセットから。0 未満にはしない |
| オーバーラップ | オフセットから。位置がオフセットより前のときは負の値も書く |
| 子音部 | オフセットから。0 未満にはしない |
| ブランク | オフセットからの時間に -1 を掛けた値 |

先行発声は、母音の開始です。子音音素だけ、その子音の開始です。

子音部は、母音の開始からスライダーで 0〜0.2 秒後です。初期値は 0.2 秒です。子音の終了は、母音の開始です。子音音素の子音部は、下の CVVC で割合になります。

ブランクは、その母音の音量から上辺の右端を取り、スライダーの秒数だけ前後にずらします。0 秒がその角です。プラスは減衰側、マイナスは手前です。幅は ±0.1 秒です。角が取れない短い母音は、母音の終了から同じ秒数だけずらします。ビブラートで角が揺れるときは、揺れの幅まで上辺を広げます。子音音素のブランクは、下の CVVC で割合になります。

ブランクと子音部のあいだが 1ms 未満になるときは、ブランクを後ろへずらします。ファイルの末尾を超えるときは、子音部を縮めて 1ms を空けます。

オーバーラップの初期値は 50% です。子音音素のブランクと子音部だけ、初期値は 100% です。

## 単独音モード

エイリアスは、そのモーラのかなです。空のときは、拡張子を除いたファイル名になります。`ん` は `N` でも `M` でも 1 エイリアスで、名前は `ん` です。母音だけの音と `ん` は、子音の開始を母音の開始と同じにします。

オフセットは、子音の開始からスライダーで ±0.1 秒です。子音の開始を 0 とします。マイナスは手前、プラスは後です。

オーバーラップは、子音の開始から母音の開始までの割合です。0% が子音の開始、100% が母音の開始です。スライダーは子音の種類ごとにあり、`k` と `sh` のように別の割合を置けます。0% で左へ引いているあいだは値を変えず、離すとその行が秒のスライダーになります。最大 0.1 秒で、オフセットより前にも置きます。右端まで戻して離すと、割合のスライダーに戻ります。母音だけの音と `ん` は、子音の開始と母音の開始が同じなので、割合を変えても位置は動きません。

先行発声、子音部、ブランクは、共通のとおりです。

## 連続音モード

エイリアスは、直前の母音と、そのモーラのかなです。`あかい` なら `- あ`、`a か`、`a い` です。先頭と、休符のあとは `-` です。`ん` の母音は `n` です。

オフセットは、その音素の開始から 0.15 秒手前です。音素の開始は、子音と直前の母音の境界です。子音がないときは、母音と母音の境界です。スライダーは ±0.1 秒です。

オーバーラップは、オフセットの位置を 0%、その音素の開始を 100% とした割合です。子音ごとのスライダーはありません。

先行発声、子音部、ブランクは、共通のとおりです。

アンダーバーだけの無音の直後の音素は、単独音の計算です。使う値は、連続音の画面で選んだ単独音のプリセットです。初期値は、オフセット 0、子音部 0.2 秒、ブランク 0、オーバーラップ 50% です。エイリアスは連続音のままです。`_あかい` の `- あ` がこれにあたり、続く `a か` と `a い` は連続音の計算です。`っ` から始まる音も、そのモーラの直前が無音なら単独音の計算です。

## CVVC モード

1 つの WAV から、通常の音素と、そのあいだの子音音素を書きます。`さしす` なら、並びは `- さ`、`a sh`、`し`、`i s`、`す` です。`っ` と、子音の無い `ん` には子音音素の行はありません。子音があるモーラだけ、その通常音素の前に子音音素が入ります。

### 先頭音素

ファイルの先頭と、アンダーバーだけの無音の直後です。計算は選んだ単独音のプリセットで、単独音と同じです。エイリアスは `-` と、そのモーラのかなです。あいうえおんは、ファイルの先頭ではこのプリセットを使わず、母音音素の計算です。アンダーバーの直後は、あいうえおんでもこのプリセットです。

### 通常音素

先頭以外で、子音があるモーラです。エイリアスは、そのモーラのかなだけです。

オフセットは、子音の開始です。スライダーはありません。オーバーラップは、オフセットを 0%、先行発声を 100% とした割合です。子音ごとにスライダーがあります。0% より前を秒で置く機能はありません。

先行発声、子音部、ブランクは、共通のとおりです。このオーバーラップと、通常音素の子音部・ブランク、子音音素のスライダーは、単独音とは別のプリセットに保存します。

### 母音音素

あいうえおんです。`を` と小書きの母音も同じです。子音音素の行はありません。エイリアスは、ファイルの先頭なら `- あ`、それ以外なら `あ` です。計算は連続音と同じです。

オフセットは、その母音の開始から 0.15 秒手前です。スライダーは子音音素のオフセットで、±0.1 秒です。オーバーラップは、オフセットの位置を 0%、その母音の開始を 100% とした割合です。スライダーは子音音素のオーバーラップです。子音部とブランクは、通常音素のスライダーです。位置の取り方は、共通のとおりです。

### 子音音素

エイリアスは、直前の母音と、いまの子音です。`ん` の母音は `n` です。`さ` の次の `し` は `a sh` です。オフセットとオーバーラップのスライダーは、母音音素にも使います。

オフセットは、その子音の開始から 0.15 秒手前です。スライダーは ±0.1 秒です。先行発声は、その子音が開始した秒です。オーバーラップは、オフセットの位置を 0%、その子音の開始を 100% とした割合です。

ブランクは、その子音の開始を 0%、終了を 100% とした割合です。子音部は、先行発声を 0%、ブランクの位置を 100% とした割合です。どちらも初期値は 100% で、子音ごとにスライダーがあります。重なるときは、共通の 1ms 空けに従います。

## 周波数表（.frq）

`.frq` は UTAU の周波数表です。形式は FREQ0003 で、256 サンプルごとの高さ（Hz）と振幅、それに有声の平均が入ります。高さ 0 は音程なしです。フォルダ直下の WAV と同じ名前で置き、`original` には書きません。

「.frq生成」は、この表を音響から作ります。対象は、すべて上書き、無いものだけ、選択中の 1 件です。単独音では、先行発声までを 0 にできます。エフェクターのあとや WAV を差し替えたあとは作り直します。

「frqエディター」は、選択中のファイルの `.frq` をピアノロールの点で出します。点の高さは Hz のままで、鍵盤の線のあいだにも置きます。音程なしの点は下の段です。鍵盤は C-1 から G9 です。

- カーソルは、ドラッグした矩形の中にある点を選びます。このときだけ「＋12」「-12」「-」が出ます。＋12 と -12 は選んだ点を 1 オクターブ動かします。音程なしは動きません。鍵盤の外へは出ません。- は選んだ点を音程なしにします。
- ペンは、ドラッグで通った点を、その位置の高さに書き換えます。下の段では音程なしになります。
- 離したとき、またはオクターブと音程なしのボタンを押したときに、同じ `.frq` へ書き戻します。振幅とサンプル間隔はそのままです。

ホイールで音程をスクロールし、Shift＋ホイールで時間を移動し、Ctrl＋ホイールで時間を拡大します。

## 録音

「表示」の「録音リスト」「録音スクリプト」「録音コントローラ」「ガイドBGM設定」「マイクモニター」、または配置テンプレートの「録音」です。初期配置には出ません。WAV がまだ無いフォルダも開けます。

録音リストは、録る順番の台本です。1 行が 1 テイクで、空行と `#` で始まる行は読み飛ばします。タブの右側は、息の量や語尾のようなコメントです。文字コードは CP932 と UTF-8 です。リストはドロップダウンから選びます。一番上は「選択しない」、その次は「ファイルから選ぶ」で、選ぶとファイルを開く画面が出ます。一度選んだリストは次からこの中に出ます。まだ選んでいないフォルダに `録音リスト.txt` があれば、それを開きます。上から、見出し、リストの選択、録音済みの数とリストの行数、タブです。タブは、すべて、未録音、録音済み、リスト外です。リスト外は、リストの行に無いフォルダ内の WAV で、すべてには出ません。行は、未録音、録音済み、使えない文字、のどれかです。保存するファイル名は、行の音素に `.wav` を足したものです。

録音リストで行を選ぶと、ファイルリストの同じ WAV も選ばれ、スペクトログラムと音量がその音声になります。ファイルリストで選んでも、録音リストの同じ行が選ばれます。いまのタブにその行が無いときは、リストの選択は外れ、録音スクリプトだけがその行になります。まだディスクに無い WAV では、スペクトログラムと音量に「このファイルは存在しません」と出ます。録音しただけで、まだ解析していない WAV はファイルリストに無いので、そこでは選択を外し、スペクトログラムと音量だけ出します。

録音スクリプトは、いまの行の名前を大きく出します。これが読み上げる内容です。その下にコメントと、次の行の名前が出ます。

録音コントローラは、その行が未録音か録音済みかと、停止したあとに次の未録音へ進むかです。下に前へ、次へ、次の未録音があり、その下が「録音」です。録音中は「停止」になります。F9 で録音と停止、F7 と F8 で前後、F6 で次の未録音です。文字を打っているあいだは、これらのキーは効きません。既にある WAV は、上書きする前に確認します。

ガイドBGM設定は、「ファイルを選ぶ」か「自分で設定する」かを選びます。大きさはどちらでも出て、ファイルにも効きます。ファイルを選ぶときは、WAV のドロップダウンに加えて、再生速度と音程を出します。再生速度は 50% から 200% で、音程は −12 から +12 半音です。高さだけ、または長さだけを変えます。同じ名前の txt が対になります。一度選んだ WAV は次からこの中に出ます。自分で設定するときは、音程、カウント、テンポ、録音中に鳴らすかだけを出します。カウントは 1 小節で、テンポは BPM です。「ガイドを聴く」はこのパネルの下にあり、F11 です。

保存は 44.1 kHz、16 bit、モノラルです。ステレオの入力は混ぜます。先頭の無音は切りません。録音のたびに解析は走らず、あとから「解析」でまとめてかけます。マイクの入力と、ガイドとテイクを鳴らす出力は、「編集」の「環境設定」にある「入出力」で選びます。ガイドの音名、大きさ、ファイルの再生速度と音程も、この PC に覚えます。一度選んだ録音リストのパスと、ガイドの WAV も、この PC に覚えます。いまのフォルダで選んでいるリストとガイドは、音源フォルダの `OTOasibi_録音.json` に覚えます。

マイクモニターは、波形がパネルの本体です。録音していない行を選ぶとマイクの直近 3 秒、録音済みの行を選ぶとその WAV を出します。右のレベルメーターはマイクのレベルです。左上の小さなトグルで、入っている音を出力から出せます。既定はオフです。スピーカーの音をマイクが拾うことがあります。下の「テイクを聴く」で保存した WAV を再生し、再生中は「停止」になります。F10 です。再生位置が波形の上を動きます。パネルを閉じると、このモニタは止まります。

## インストール

配布版は [Releases](https://github.com/mucha0w0/OTOasobi/releases) の `OtoasobiSetup.exe` です。Windows 64 ビット用です。いまの版は開発中のベータです。

`OtoasobiSetup.exe` を実行すると、`%LocalAppData%\Otoasobi` に入ります。署名はまだ無いので、初回は SmartScreen が出ます。「詳細情報」から実行します。画面は WebView2 で表示します。ランタイムが無いときは、起動時に案内を出します。WinAppSDK の自己完結には、このランタイムは入りません。

初回起動では、高精度エンジン（torch、Praat、音声モデル）をダウンロードするか聞きます。サイズはダイアログに出ます。進めると `%LocalAppData%\Otoasobi\engine` と `models` に入ります。断ったとき、またはダウンロードに失敗したときは、音響エンジンで動きます。あとからファイルメニューの「更新を確認」でも準備できます。

2 回目以降は、起動時と「更新を確認」で GitHub の最新リリースを見ます。新しければ「バージョン x があります」と出て、進めるとアプリを差し替えて起動し直します。最近使ったフォルダやプリセットは、更新では消えません。アンインストールすると、`%LocalAppData%\Otoasobi` ごと消えます。

更新の確認は、Setup から入れたアプリが行います。

## リリース

`prototype/host/Otoasobi.Probe.csproj` の `Version` と、タグの `v` を除いた番号を同じにします。タグを push すると、GitHub Actions がページをビルドしてから `Otoasobi.exe` を作ります。

```powershell
git tag v0.1.0-beta.1
git push origin v0.1.0-beta.1
```

ハイフンを含む版（`0.1.0-beta.1` など）は、GitHub ではプレリリースになります。その版を入れているアプリは、次のプレリリースも更新として見ます。ハイフンの無い版は、プレリリースを見ません。

初回は CPU 版の torch と音声モデルを取るので、Actions は時間がかかります。リリースに載る主なファイルは次です。

| ファイル | 役割 |
| --- | --- |
| `OtoasobiSetup.exe` | 画面と音響エンジン。利用者が実行する |
| `OtoasobiEngine.zip` | 高精度エンジン。アプリが展開する |
| `mms-fa-model.pt` | MMS の重み。アプリが配置する |
| `engine.json` | エンジンとモデルの版と SHA256 |

画面だけの更新は Setup の差分です。エンジンとモデルは、`engine.json` のハッシュが変わったときだけ落とします。

## 必要環境

- Windows
- .NET 10 SDK（画面のホスト）
- Node.js 22（配布する画面）
- Python 3.12（解析）

解析の依存は `requirements.txt` です。

- numpy
- soundfile

高精度エンジンは `requirements-precision.txt` の `praat-parselmouth`、`torch`、`torchaudio` です。`.venv` に入っているとき、OTOasobi の解析でも使います。

## セットアップ

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-precision.txt
```

.NET 10 SDK は [ダウンロードページ](https://dotnet.microsoft.com/download) から入れます。入っているかは `dotnet --version` で確認できます。

## 起動

配布する画面です。`prototype/ui` の React を、`prototype/host` が WebView2 で開きます。解析は「セットアップ」の Python を使います。

初回だけ、画面のパッケージを入れます。

```powershell
cd prototype/ui
npm install
```

ターミナルを 2 つ使います。先に開発サーバーを起動します。

```powershell
cd prototype/ui
npm run dev
```

`http://localhost:5173` で待ちます。もう一方は、リポジトリのルートからホストです。

```powershell
dotnet run --project prototype/host
```

`prototype/host/Properties/launchSettings.json` が環境変数 `OTOASOBI_PROBE_URL` を `http://localhost:5173` にします。ホストはこのアドレスを開きます。画面のファイルを保存すると開発サーバーが差し替えるので、ホストはそのままです。

すでにオトアソビが起動していると、同じ `Otoasobi.exe` をビルドできず失敗します。起動中のアプリを終了してから、もう一度実行します。

起動するとトップ画面が出ます。「既存のフォルダを選ぶ」を押すとフォルダ選択が開き、最近使用したフォルダの一覧からも開けます。ウィンドウへドロップしても開けます。WAV がまだ無いフォルダも開けます。WAV があるフォルダは、直下の `.wav` をすべて解析し、波形とメルスペクトログラムに区間を重ねて表示します。境界をドラッグすると隣の区間と時刻を分け、ラベルの上をドラッグするとその区間ごと移動します。音素推定、スペクトログラム、音量、oto設定の上にカーソルがあるとき、ホイールでファイルリストの前後の音声へ移ります。時間方向の移動は Shift＋ホイール、拡大は Ctrl＋ホイールです。ほかのパネルの上では、そのパネルの中を縦にスクロールします。音量の下の oto.ini では、線をドラッグしてその値だけを直せます。直したあとに「oto.ini作成」を押すと、oto調整で選んだモードで計算した `oto.ini` と、`OTOasibi_out.txt`、`OTOasibi_log.txt` をフォルダに保存します。線で直した値があるときは、その位置を使います。「oto.iniを開く」で `oto.ini` を開きます。

ファイル名に使えない文字があるときは、その理由を表示します。

## 設定の保存

ファイルメニューの「設定を保存」は、いまの計算方法（単独音、連続音、CVVC）と、各モードのスライダーと、プリセットと、線で直した値を、開いているフォルダの直下に保存します。原音修正のプリセットと、かかっているエフェクトの値も含みます。ファイル名は `OTOasibi_` で始まります。「設定を読み込む」で、そのフォルダのファイルを選んで戻します。読み込むと、プリセット一覧と、線で直した値は、そのファイルの内容になります。

スライダー、計算方法、線の位置を変えると、同じフォルダの `OTOasibi_作業中.json` も更新されます。そのフォルダを次に開いたときは、その状態から始まります。`OTOasibi_作業中.json` は一覧には出ません。

## ファイル名

拡張子を除いた名前が読み仮名です。使える文字はひらがな、カタカナ（`ヴ` を含む外来音）、休符 `_` だけです。半角カナの `ｳﾞ` や、濁点を離した `ウ゛` も `ヴ` として読みます。

| 記法 | 意味 |
| --- | --- |
| `そ` `せ` `しゃ` `つ` | 1 モーラ。拗音・外来音は 2 文字で 1 モーラ |
| `_` | 休符。連続した `_` は 1 つの無音 |
| 先頭の `_` | 発話前の無音 |
| 末尾の `_` | 発話後の無音 |
| 途中の `_` | モーラのあいだの無音 |

例: `_そせすそそ.wav` は、無音、そ、せ、す、そ、そ、無音、の順です。

`ん` の直後がま行・ば行・ぱ行のときはラベルが `M` になります。`っ` は閉鎖 `cl` です。同じ母音が続く `ああ` や `かあ` は、いったん 1 区間として合わせてから、元のモーラ数で等分します。

使えない文字や、単独の `ゃゅょ` はファイル名エラーになります。

## ラベルファイル

`OTOasibi_out.txt` は、母音の始まり時刻だけです。タブ区切り、UTF-8、1 行が 1 モーラです。

```text
かな	母音の開始秒
```

ラベル名は、そのモーラのかなです。子音から母音へ入る時刻、前の母音から次の母音へ入る時刻を出します。`ん` は `N` でも `M` でも母音と同じように扱い、ラベル名は `ん` です。無音、息、子音、`っ` の行は出しません。

`ぱんぱぱぴぱぷあ.wav` の音素が `無音 p a N p a p a p i p a p u a` のとき、着目するのは `(p→a) (a→N) (p→a) (p→a) (p→i) (p→a) (p→u) (u→a)` です。

```text
[ぱんぱぱぴぱぷあ.wav]
ぱ	0.180000
ん	0.420000
ぱ	0.610000
ぱ	0.790000
ぴ	0.980000
ぱ	1.160000
ぷ	1.350000
あ	1.540000
```

## ログファイル

`OTOasibi_log.txt` は、推定に使った全区間です。無音、息、子音、母音を残します。1 行が 1 区間です。

```text
開始秒	終了秒	音素	かな
```

`_そせすそそ.wav` の例:

```text
0.000000	0.160000	無音	_
0.160000	0.238390	s	そ
0.238390	0.652494	o	そ
0.652494	0.732381	s	せ
0.732381	1.162494	e	せ
```

音素はローマ字です。母音は `a i u e o`、子音は `s` `sh` `k` `ts` `ch` など、撥音は `N` または `M`、促音は `cl` です。かな列は、その区間が属すモーラの表記です。開発用画面で 1 ファイルを解析したときは、同じ内容を `ファイル名.log.txt` に保存します。

## 解析エンジン

| エンジン | 内容 |
| --- | --- |
| 高精度 (MMS+Praat) | torchaudio の MMS-FA で文字を合わせ、Praat で発話区間・声帯振動・フォルマントを補正する |
| 高精度 (MMS) | MMS-FA のみ。Praat が無い、または使えないとき |
| 音響 | RMS、高域比、ゼロ交差、スペクトル変化だけで区間を切る |

高精度の読み込みに失敗したときは音響へ戻ります。

## 開発用の確認画面

`app.py` は解析結果を波形とメルスペクトログラムで見るための開発用画面です。OTOasobi には組み込みません。

```powershell
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m otoasobi.cli そせす.wav
```

開発用画面の exe は `powershell -File scripts\build_exe.ps1` で、`dist\OtoasobiLabel\OtoasobiLabel.exe` に出力されます。高精度エンジンは同梱しません。配布版の `OtoasobiSetup.exe` とは別のファイルです。
